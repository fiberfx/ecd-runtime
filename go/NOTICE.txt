Entity Component Runtime: parts taken from other projects

This file lists every part of Entity Component Runtime (ECR) that is taken from another project, and the projects whose
design Entity Component Runtime follows without taking code. It has two sections. Parts taken: each entry names the
project, its source repository and commit, its licence and copyright line, what is taken, and the files that hold it.
Each such file begins with the entry's attribution line, and the licence text that the project's licence requires
follows the entry. Foundational references: each entry names a project, its source repository and commit, its licence
and copyright line, and the design ideas that Entity Component Runtime follows from it. No code is taken from these
projects.

Entity Component Runtime's own code is under the MIT License; its text is in LICENSE at the module root.

Foundational references

2. GOKe

Project:     GOKe
Source:      https://github.com/kjkrol/goke
Commit:      aa6f5bd40b3c436309844e83f8e78301cb467acc
Licence:     MIT License
Copyright:   Copyright (c) 2024 kjkrol

Entity Component Runtime follows GOKe's design for stages under a plan, a command buffer per system with a flush at
explicit sync points, a scheduler that reaches storage only through an interface, readers on several goroutines that
each hold a cursor over one matcher, a monotonic structural version per table, one spare chunk kept on shrink, and
compaction strategies for bulk moves. No code is taken.

3. donburi

Project:     donburi
Source:      https://github.com/yohamta0/donburi-ecs (the Go module path is github.com/yohamta/donburi)
Commit:      24e87dc2201a9e2ecefb22ed91ff450c091b117a (v1.15.8)
Licence:     MIT License
Copyright:   Copyright (c) 2022 Yota Hamada
             The project's LICENSE also carries the MIT notices of Copyright (c) 2020 Thomas Gillen,
             Copyright (c) 2021 Artem Sedykh and Copyright (c) 2021 Wojciech Franczyk.

Entity Component Runtime follows donburi's API shapes: typed component handles as package-level values, value accessors,
a handle that doubles as a one-component query, filter terms as composable values (All, None, Any, Exact),
range-over-func iteration, presence checks for optional components, data-less tags, typed events and lifecycle hooks,
and per-archetype counts. No code is taken.

4. Volt

Project:     Volt
Source:      https://github.com/akmonengine/volt
Commit:      d6236fec0f28c664e1a19cd7f0773013958c4532
Licence:     Apache License 2.0
Copyright:   Copyright 2024, Agoune Ramine

Entity Component Runtime follows Volt's design ideas and test cases: checks before placement, the generation step tested
at its limit, a dead-handle soak, empty-archetype placement cases, and benchmark scenarios in a nested module. No code
is taken.
